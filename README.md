# Fly on the Wall — Prototype

Interactive proof-of-concept for **Fly on the Wall**, a company-intelligence product for job seekers.

## Current prototype

- Search/select a demo company
- Company overview and letter grades
- "What Fly Found" key signals
- Hiring snapshot
- Job-seeker readout
- Deep dives for:
  - Business stability
  - Hiring & workforce
  - Employees
  - Customers & product
  - Opportunity / job credibility
  - Sources
- Clickable evidence layer
- Responsive desktop/mobile layout

## Demo companies

- Amazon
- Cruva

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

Repository settings → Pages → Deploy from branch → `main` → `/ (root)`.

> Note: GitHub Pages availability depends on repository visibility and GitHub plan. If Pages is unavailable while the repository is private, make the prototype repository public or use another free static host.
